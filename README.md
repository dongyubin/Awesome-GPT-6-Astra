## GPT-6 Astra是什么？

GPT-6 Astra 是 OpenAI 面向复杂工作和 AI Agent 场景推出的新一代模型。

它并不是一个独立的办公软件，而是可以运行在 ChatGPT、Codex、ChatGPT Work 和 API 等产品中的模型能力。

简单来说，普通 AI 更偏向：

**提出问题 → 生成答案。**

Astra 则进一步强调：

**提出目标 → 理解任务 → 调用工具 → 执行步骤 → 交付结果。**

例如需要制作一份经营分析报告时，它可以结合数据分析、文件处理和文档生成能力，完成从资料整理到最终交付的多个步骤。
